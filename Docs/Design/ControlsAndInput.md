# 조작과 입력

## 설계 원칙

Zorba의 조작은 **패드 우선**으로 설계하고, 그 다음 키보드/마우스로 옮깁니다.

키보드/마우스는 버튼 수가 많아 기능이 늘어도 흡수하기 쉽습니다. 반대로 패드는 초반에 편하지 않으면 게임 구조 자체가 불편해집니다.

입력의 기준은 하나로 둡니다.

- 물리 키 배치: `IMC_Gameplay` Enhanced Input 에셋
- 입력 액션 에셋: `IA_*`
- 기본 스폰 경로: `BP_ZorbaGameMode -> BP_ZorbaCharacter`
- 행동 처리: C++ `ZorbaCharacter`
- `DefaultInput.ini`: Enhanced Input을 쓰기 위한 엔진 설정만 유지

즉, 키를 바꾸거나 프리셋을 만들 때는 `DefaultInput.ini`나 C++에 키 이름을 추가하지 않고 `IMC_Gameplay`와 이후 입력 설정 UI를 통해 바꿉니다.

## 전투 액션 모델

Zorba는 "기술을 하나씩 넘긴 뒤 사용 버튼을 누르는 방식"이 아니라, **금단 기술 슬롯 4개를 직접 누르는 방식**을 기본으로 합니다.

플레이어는 캐릭터별 고정 금단 기술 4개와 별도 이동 기술인 어둠의 형상을 가집니다. 그래서 금단 계열 입력은 총 5개입니다.

- 금단 기술 슬롯 1
- 금단 기술 슬롯 2
- 금단 기술 슬롯 3
- 금단 기술 슬롯 4
- 어둠의 형상

신성한 계율은 방어, 패리, 회피, 강공격처럼 정공법 공방을 담당하고 신성력을 소모합니다. 금단 기술은 적의 불합리한 패턴이나 특수 상태를 깨는 강한 도구이며, 첫 버전에서는 넓은 빌드 조합을 목표로 하지 않습니다.

신성한 계율과 금단 기술은 실력 단계로 나뉘지 않습니다. 신성한 계율만으로는 위험하거나 파훼가 어려운 적 패턴이 있고, 그런 순간에 금단 기술을 능동적으로 써서 패턴을 부숩니다.

### 전투 상태별 입력 우선순위

| 대상 상태 | 입력 | 결과 |
| --- | --- | --- |
| 일반 | `PrimaryAttack` | 기본 공격 |
| `Exhausted`이며 기회공격 범위 안 | `PrimaryAttack` | 기회공격 |
| 체력이 처형 기준 이하 | `ContextAction` | 처형 |
| `Exhausted`이면서 처형 가능 | `PrimaryAttack` / `ContextAction` | 기회공격 / 처형을 입력별로 선택 |

체력은 사망과 처형만 결정합니다. 적의 `CombatStamina`는 공격과 방어 같은 행동에 소비되고 패리로 크게 감소하며, 0이 되면 일시적인 `Exhausted` 상태와 기회공격 창을 엽니다. 기회공격은 마커 표시, 카메라 전환, 플레이어가 통제권을 잃는 구간의 무적을 하나의 행동으로 관리합니다.

## 패드 기본안

| 의도 | 입력 |
| --- | --- |
| 이동 | 왼쪽 스틱 |
| 카메라 | 오른쪽 스틱 |
| 기본 공격 | RT / R2 |
| 강공격 | RB / R1 |
| 방어 / 패리 | LB / L1 |
| 금단 기술 레이어 | LT / L2 누르고 있기 |
| 금단 기술 1 | LT + A / Cross |
| 금단 기술 2 | LT + B / Circle |
| 금단 기술 3 | LT + X / Square |
| 금단 기술 4 | LT + Y / Triangle |
| 회피 | A / Cross |
| 어둠의 형상 | B / Circle |
| 상호작용 / 처형 | X / Square |
| 캐릭터 액션 / 태세 | Y / Triangle |
| 성유물 / 회복 | D-pad 아래 |
| 목표 표시 | D-pad 위 |
| 달리기 토글 | 왼쪽 스틱 클릭 |
| 일시정지 | Menu / Options |

현재 C++ 입력 처리는 `LT / L2`를 금단 기술 레이어로 기억합니다. 그래서 `LT`를 누른 상태에서 A/B/X/Y를 누르면 기존 회피/어둠의 형상/상호작용/캐릭터 액션 대신 금단 기술 슬롯 1/2/3/4가 요청됩니다.

달리기는 이동 중에만 유효합니다. 이동 중 스프린트 입력을 누르면 토글되고, 이동을 멈추면 자동으로 꺼집니다. 스프린트 입력을 누른 상태로 이동을 시작해도 달리기로 들어갑니다.

회피는 입력 순간의 이동 입력을 카메라 기준 방향으로 사용합니다. 이동 입력이 없을 때는 캐릭터 전방으로 회피합니다.

| 금단 기술 2 | 2 |

## UI 기본안

| 의도 | 키보드/마우스 | 패드 |
| --- | --- | --- |
| 포커스 이동 | WASD / 방향키 / 마우스 | D-pad / 왼쪽 스틱 |
| 확인 | Enter / 좌클릭 | A / Cross |
| 뒤로가기 | Esc / 우클릭 | B / Circle |
| 이전 탭 | Q | LB / L1 |
| 다음 탭 | E | RB / R1 |
| 값 초기화 | R | Y / Triangle |
| 스크롤 | 마우스 휠 | 오른쪽 스틱 |

첫 UI는 복잡한 가상 커서 화면보다 포커스 이동이 명확한 메뉴를 우선합니다. 가상 커서는 나중에 복잡한 화면이 필요해질 때 보조로 추가합니다.

## 첫 입력 액션 이름

코드와 에셋이 공유할 플레이어 의도 이름입니다.

`UseAbilitySlot1~4`라는 코드 이름은 아직 일반적인 ability 표현을 쓰지만, 디자인 의미는 금단 기술 슬롯입니다. 신성한 계율은 기본 공방 입력 위에 붙습니다.

약공격은 가까운 적을 향한 약한 유도 성능을 갖는 평타입니다. 유효한 `Exhausted` 적이 가까이 있으면 같은 입력이 기회공격을 우선합니다. 강공격은 단독으로도 쓰지만, 약공격 1타 후 강공격, 약공격 2타 후 강공격처럼 연타 흐름 뒤에 붙었을 때 다른 파생으로 확장할 수 있습니다. 어떤 파생이 실제로 가능한지는 애니메이션과 판정 리소스가 준비된 뒤 확정합니다.

```text
Move
Look
PrimaryAttack
HeavyAttack
Defend
Dodge
DarkForm
Sprint
AbilityLayer
ContextAction
ClassAction
UseAbilitySlot1
UseAbilitySlot2
UseAbilitySlot3
UseAbilitySlot4
UseRelic
ShowObjective
Pause
UIConfirm
UIBack
UINavigate
UITabNext
UITabPrev
UIReset
```

첫 슬라이스에서는 미루는 입력입니다.

```text
LockTarget
Reload
SwitchWeapon
UseEquipment
Ping
Chat
Scoreboard
```
