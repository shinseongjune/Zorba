# 버티컬 슬라이스 계획

## 목표

Zorba의 가장 작은 플레이 가능 형태를 증명합니다.

```text
타이틀 또는 임시 시작 흐름
작은 미션 공간
근접 이동과 카메라
기본 공격, 강공격, 방어, 회피
불경한 대쉬
기술 4개 요청
성유물 또는 회복 요청
적 무리 프로토타입
처형 프로토타입
미션 성공/실패 후 복귀 흐름
```

첫 슬라이스에는 최종 아트, 최종 UI, 완성 애니메이션, 전체 현지화, 완전한 스토리 챕터가 필요하지 않습니다.

## 1단계 - 입력 계약

목적: 전투 세부 구현 전에 프로젝트가 플레이어의 의도를 같은 이름으로 이해하게 만듭니다.

작업:

- gameplay 키 배치는 `IMC_Gameplay` Enhanced Input 에셋에서만 관리합니다.
- `Config/DefaultInput.ini`는 Enhanced Input 사용을 위한 엔진 설정만 남깁니다.
- 이동, 카메라, 일시정지, 공격 요청, 회피, 불경한 대쉬, 방어, 캐릭터 액션, 기술 슬롯, 성유물, 목표 표시, 카메라 리셋을 바인딩합니다.
- 처음에는 이동만 실제로 작동하고, 전투 액션은 로그와 Blueprint 이벤트로 연결합니다.

이유:

입력을 늦게 바꾸면 UI, 전투, 애니메이션, 튜토리얼을 함께 뜯어고치게 됩니다. `PrimaryAttack`, `ContextAction`, `UseAbilitySlot1` 같은 이름을 먼저 안정시키면 이후 시스템들이 같은 언어를 쓰게 됩니다.

## 2단계 - 회색 박스 캐릭터 전투

목적: 콘텐츠를 넣기 전에 캐릭터가 근접 전투원처럼 느껴지는지 확인합니다.

작업:

- 기본 공격 임시 구현
- 강공격 임시 구현
- 방어 또는 패리 상태
- 회피 이동
- 쿨다운이 있는 불경한 대쉬
- 공격 소프트 유도
- 기본 타격 판정

## 3단계 - 적 무리 프로토타입

목적: 여러 적이 가까이 몰려올 때 재미가 생기는지 확인합니다.

작업:

- 약한 적 1종
- 단순 접근과 공격 행동
- 피격 반응
- 처형 가능 상태
- 테스트 공간에 소규모 무리 스폰

## 4단계 - 신성한 기술과 비겁한 기술

목적: 게임의 주제를 시스템으로 표현합니다.

작업:

- 신성력 자원
- 신성력을 쓰는 신성한 기술 1개
- 쿨다운 또는 충전형 비겁한 기술 1개
- 기술 사용 가능 상태를 보여주는 임시 UI

## 5단계 - 처형과 회복

목적: 주요 생존 루프를 만듭니다.

작업:

- 적을 처형 가능 상태로 표시
- 컨텍스트 액션이 가능한 경우 처형을 우선 선택
- 처형으로 체력 또는 신성력 회복
- 처형 중 짧은 안전 시간 제공

## 6단계 - 최소 UI 흐름

목적: 테스트맵이 아니라 게임처럼 느껴지게 만듭니다.

작업:

- 타이틀 또는 임시 메인 메뉴
- 일시정지 메뉴
- 언어와 조작 표시가 있는 옵션 뼈대
- 미션 종료 화면

## 초보자 작업 메모

### C++ 클래스로부터 블루프린트 자식 만들기

1. 언리얼 에디터를 엽니다.
2. 아래쪽 **Content Drawer**를 엽니다.
3. `Content/00_Core/Blueprints` 폴더를 만듭니다.
4. 폴더 안에서 우클릭합니다.
5. **Blueprint Class**를 선택합니다.
6. 원하는 클래스가 바로 보이지 않으면 **All Classes**를 엽니다.
7. 예를 들어 `ZorbaCharacter`를 검색합니다.
8. 선택해서 자식 블루프린트를 만듭니다.

C++ 클래스는 자동으로 기본 동작을 제공합니다. 블루프린트 자식은 메시, 애니메이션 블루프린트, 사운드, VFX, 디자이너가 조절할 값들을 넣는 곳입니다.

### 나중에 Enhanced Input 에셋 만들기

1. Content Drawer에서 `Content/00_Core/Input` 폴더를 만듭니다.
2. 폴더 안에서 우클릭합니다.
3. **Input > Input Action**을 선택합니다.
4. `IA_Move`, `IA_Look`, `IA_PrimaryAttack` 같은 이름으로 액션을 만듭니다.
5. 다시 우클릭해서 **Input > Input Mapping Context**를 선택합니다.
6. `IMC_Gameplay`를 만듭니다.
7. `IMC_Gameplay`를 열고 각 Input Action에 키보드와 패드 입력을 배정합니다.

현재 C++ 임시 입력은 바로 시작하기 위한 발판입니다. 캐릭터와 UI의 첫 형태가 안정되면 Enhanced Input 에셋으로 옮기는 것이 좋습니다.
