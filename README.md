# Zorba

Zorba는 성스러운 질서와 금단의 실전술이 충돌하고 조화를 찾는 **숄더뷰 3D 근접 액션 게임**입니다.

이 게임은 정해진 캐릭터가 이야기 진행에 따라 기술을 해금하며 적 무리를 근접전으로 돌파하는 미션형 호드 액션입니다.

## 방향성

핵심 긴장은 **신성한 규율**과 **단일 신념만으로 평가할 수 없는 현실** 사이에 있습니다.

- **신성한 계율**은 방어, 패리, 회피, 강공격처럼 정공법 공방을 담당하고 신성력을 소모합니다.
- **금단 기술**은 쿨다운이나 충전으로 제한하며, 적의 불합리한 패턴이나 특수 상태를 깨는 역할을 합니다.
- **어둠의 형상**은 금단 기술 4슬롯과 별도인 이동 기술입니다. 어두운 안개 형상으로 변해 빠르게 이동하고 적을 관통합니다.
- **처형**은 핵심 루프입니다. 단순한 멋진 연출이 아니라 체력, 신성력, 숨 쉴 틈을 되찾는 생존 수단이어야 합니다.
- **조르바형 멘토는 멋진 악동 영웅이 되면 안 됩니다.** 매력적이고 도움이 되지만, 분명히 잘못되었고 해로운 면도 있어야 합니다.

첫 버티컬 슬라이스는 다음 루프를 증명하는 것을 목표로 합니다.

```text
작은 미션 공간에 진입한다
근접 공격, 방어, 회피, 소프트 유도로 적 무리를 상대한다
신성한 계율로 정면 공방을 받아치고 자세를 무너뜨린다
금단 기술로 정공법으로는 깨기 어려운 패턴을 부순다
처형으로 체력과 신성력을 회복한다
성공/실패 흐름을 거쳐 미션을 마친다
```

## 현재 조작 철학

Zorba는 **패드 우선**으로 설계하고, 그 다음 키보드/마우스로 옮깁니다.

키보드/마우스는 버튼 수가 많아 나중에 수습하기 쉽지만, 패드는 초반에 편하지 않으면 게임 구조 전체가 불편해집니다.

첫 액션 세트는 다음 정도로 제한합니다.

- 이동, 카메라, 기본 공격, 강공격, 방어, 회피, 달리기
- 상호작용/처형/대화/부활을 겸하는 컨텍스트 액션
- 캐릭터 고정 금단 기술 4개
- 어둠의 형상 1개
- 신성한 계율 해금과 발동 조건
- 성유물 또는 회복 슬롯 1개
- 목표 표시와 일시정지

락온, 탄약 관리, 장비 슬롯, 핑, 채팅, 점수판은 첫 슬라이스에서는 제외합니다.

자세한 조작안은 [Docs/Design/ControlsAndInput.md](Docs/Design/ControlsAndInput.md)에 정리되어 있습니다.
